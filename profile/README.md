# Johan Hartman Group - Bioinformatics & Machine Learning

**Research software and computational workflows | Karolinska Institutet**

Johan Hartman's research group brings together clinicians, pathologists, and computational researchers working on breast cancer and precision pathology.

**This GitHub organization is maintained primarily by the group's bioinformaticians and machine learning engineer.** It serves as a platform for sharing research software, bioinformatics pipelines, machine learning code, and reproducible computational analyses.

Our work spans molecular subtyping, cancer genomics, spatial transcriptomics, computational pathology, and tumour heterogeneity.
