# Johan Hartman Group

**Bioinformatics · Computational biology · Machine learning**

[Karolinska Institutet][ki] · [Lab website][lab] · [Repositories][repos]

We share bioinformatics software, computational workflows, and analysis code supporting breast cancer and precision pathology research in Johan Hartman's group at **Karolinska Institutet**.

Our work spans molecular subtyping, tumour heterogeneity, and the integration of genomic, transcriptomic, spatial, and clinical data.

## Selected repositories

- **[BreastSubtypeR][bsr]** — An R/Bioconductor package for intrinsic molecular subtyping of breast cancer gene-expression data.
- **[BreastCancer_CTA][cta]** — Tools for aligning computational tissue annotations from histology images with spatial transcriptomics data.
- **[BreastCancer_Multiregion][multiregion]** — Analysis workflows for spatial transcriptomics and DNA copy-number variation in breast cancer.
